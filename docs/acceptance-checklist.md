# 功能验收清单

对应题目 R-01～R-14。“源码已写”与“实际验证”分开记录；未做或环境无法验证的项如实标注，不宣称通过。最近一次验证时间：2026-10-29（macOS + Docker Compose，详见 README“测试、构建与验证记录”）。

| 要求 | 源码状态 | 实际验证 |
| --- | --- | --- |
| R-01 技术栈与职责 | 前端 Next.js 16 App Router + React 19 + TypeScript；后端 Java 21 + Spring Boot 3.5 + MyBatis；MySQL 持久化。模板、素材、任务、历史由 Java 提供，Next 通过同源 `/api` 代理调用并展示 | 真实 Compose 环境：Next → Java → MySQL 链路可用；模板/上传/任务/历史接口均返回真实数据库数据 |
| R-02 列表与模拟数据 | 12 个模板、5 个分类（全部/人像/生活/自然/创意图片），本地封面 JPEG，Java 接口读取，分类筛选 | 接口返回 12 条；列表页截图与 UI-01 布局比对；分类切换验证 |
| R-03 详情、上传与提交前校验 | 标题/描述/封面/要求/上传位；选择、预览、替换、移除、上传中/失败反馈；数量/类型/大小客户端 + 服务端校验；提交中禁用；加载/错误/空/不存在状态；文件存本地卷 | 浏览器实际上传/替换/移除；服务端拒绝非法数量/跨用户素材（后端测试）；未登录与 404 状态代码路径 |
| R-04 受理与异步执行 | POST `/api/tasks` 完成校验、任务记录与额度扣减后返回 taskId（202），线程池后台执行；关闭页面不影响服务端任务；支持多任务排队/并行 | 真实接口提交后立即返回，右侧面板随后更新；多个任务先后提交互不影响；容器重启前的任务行为见“已知限制” |
| R-05 多步骤状态与查询 | `ASSET_CHECK → GENERATING → FINALIZING` 逐步持久化状态/阶段/事件；成功写 `result_url`，失败写 `failed_stage`/`error_message`；查询只读；终态受状态条件保护不可回退 | 后端单元测试验证阶段顺序、真实结果文件、失败中断；真实 MySQL 记录阶段与事件；查询不会推进任务 |
| R-06 失败与模拟控制 | 详情页齿轮面板可重复选择 `ASSET_CHECK`/`GENERATING`/`FINALIZING` 失败，可调 500～10000ms；无随机失败；README 说明操作 | 实际提交指定失败任务，确认在对应阶段停止并保存可读原因；调整耗时后观察处理中与多任务状态 |
| R-07 状态表达与请求异常 | 区分上传中、提交中、等待、处理中（含阶段）、成功、失败；受理成功后按钮恢复；展示失败原因/成功结果；查询异常保留已有任务并显示同步失败 + 重新查询 | 前端测试覆盖“查询异常不变成业务失败”；浏览器 DevTools 离线/接口异常时黄条出现且任务状态保留；阶段与失败文案实际展示 |
| R-08 多任务与查询生命周期 | 每个任务独立 query/task id + user 隔离；仅 QUEUED/RUNNING 每 ~2s 轮询，终态停止；无活动任务不轮询；切换用户时取消/清空查询与页面重挂载 | 前端测试覆盖多任务互不串扰、终态不回退；实际连续创建多个任务并观察状态独立；切换演示用户后数据隔离 |
| R-09 刷新恢复与结果记录 | `/history` 展示任务、创建时间、状态、成功结果或失败原因；刷新后从 Java 恢复并继续跟踪未完成任务；成功结果可图片预览 | 刷新/重开页面后历史与进行中任务恢复；结果图片可打开；分页可用 |
| R-10 用户身份与个人记录 | 两个 MySQL 演示用户；首次访问默认登录用户 1，登出状态记忆；账户弹窗可切换用户/查看额度；任务与素材按用户隔离；README 说明演示方法 | 真实接口验证用户隔离、额度扣减与方案切换；浏览器验证切换用户后历史/任务隔离；身份非真实认证的限制已注明 |
| R-11 参考界面与交互 | 按 UI-01/02/03 与账户设置截图对齐；深色主题、响应式（6/4/3/2 列、详情单列）、语义化按钮/链接、图标 aria-label、键盘焦点样式 | 1280×706、1280×650、390×844 截图逐页比对；键盘 Tab/Enter 抽查；小屏列表与详情可操作 |
| R-12 CI 与关键测试 | `.github/workflows/ci.yml`：前端 npm ci + lint + typecheck + test + build；后端 `./mvnw test` + package。后端测试覆盖阶段顺序/失败中断；前端测试覆盖多任务隔离与查询异常 vs 任务失败 | 本地按 CI 顺序执行通过：前端 13/13、后端 4/4、`next build` 成功；未在 GitHub 远端实际运行 Actions |
| R-13 提交材料与说明 | README 覆盖版本、结构、命令、配置、初始化、接口、状态机、演示、身份方案、已知限制、部署回滚、AI 工作流、素材来源；附锁文件与数据库初始化 | README、docs/cover-sources.md、CI、Compose、锁文件齐备；本清单如实记录完成度 |
| R-14 容器交付 | `docker compose up --build` 启动前端、Java 后端、MySQL 8.4；Dockerfile、`.env.example`、初始化 SQL 与启动说明齐备 | `docker compose config --quiet` 通过；`up --build` 后首页 200、模板接口 12 条、上传/提交/结果/历史/账户接口可用（详见 README 验证记录） |
