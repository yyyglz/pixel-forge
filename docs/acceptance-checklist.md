## 当前未实现或受限的功能

真实 AI/支付/第三方账号、复杂模板后台、会员积分体系、国际化平台、集群与消息队列、**服务重启后自动恢复执行**、任务受理幂等/断点续跑均未实现。进程存活时对失败状态写入和结果文件清理有有限重试；重启后不会恢复这些内存重试或重新执行任务。

## 本次审查修复（2026-10-30）

- 账户请求绑定发起时的用户与会话，旧请求迟到不覆盖切换后的账户；组件测试使用延迟响应复现。
- 历史列表已有数据时同步失败保留卡片并提供重试；组件测试覆盖先成功后失败。
- 单体进程存活期间重试失败状态写入及结果清理；不会扫描活动任务，也不恢复重启前的内存队列。数据库异常与文件清理竞态使用 Mockito 测试，不能据此声称持久化投递或多实例安全。
- 模板详情展示中英文描述；组件测试覆盖两种语言。

## 独立验收问题后续修复（2026-10-30）

- 受理后以 taskId 保留任务入口并同步服务端状态；历史失败、账户列表重试有组件回归。
- Java 对缺少身份头、畸形 JSON 和缺少 multipart 返回 400；隔离容器实测。
- 线程池拒绝时同事务记录失败及返还额度；26 个任务实测 2 个拒绝后仅扣除 24 个额度。数据库故障期间的待补偿项仍只保存在进程内。
- npm 锁文件根级 jiti 元数据补齐；Node 22 Linux 干净安装不再出现损坏警告，其他平台未复测。
